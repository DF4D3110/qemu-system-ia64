================
qemu-system-ia64
================

This repository contains an experimental QEMU full-system emulation target
for IA-64/Itanium guests.

See `README.md <README.md>`_ for build instructions, supported machines and
CPUs, runtime configuration, tests, and project-specific contribution
guidance.

This fork is based on QEMU, but project-specific patches and bug reports must
not be sent to the upstream QEMU project. For upstream QEMU itself, see
`qemu.org <https://www.qemu.org/>`_.
